# Contributing

Thanks for helping build Aimlake Open Telematics.

1. Read [`docs/PLAN.md`](docs/PLAN.md) and keep partner logic (Grabbey, Torqon, AIVAS) **out of core**.
2. Prefer small, documented PRs with tests where behavior changes.
3. Follow Apache 2.0; do not add copyleft dependencies without discussion.
4. Mobile/SDK changes must respect OS privacy and offline-first rules in the plan.
5. Scoring and collision features must remain explainable and must not claim actuarial/insurance validation unless explicitly validated and labeled.

CI will use GitHub Actions as the repo matures.
