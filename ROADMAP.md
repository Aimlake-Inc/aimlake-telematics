# Public roadmap

High-level direction for Aimlake Open Telematics. Dates are intentional goals, not commitments.

## Now — foundation

- [ ] Modular monorepo scaffold and docs (in progress)
- [ ] FastAPI `/v1` core + OpenAPI
- [ ] PostgreSQL/PostGIS + docker compose self-host path
- [ ] Security/privacy baselines (tenant isolation, auth)

## Next — product core

- [ ] Telemetry + trip engines and state machine
- [ ] Offline-first mobile SDK foundations (iOS/Android)
- [ ] Webhooks + MCP server (read-only default)
- [ ] Developer dashboard Overview + Projects + API keys

## Later — polish & OSS launch

- [ ] API playground sandbox (synthetic data)
- [ ] Telemetry simulator + published reproducible benchmarks
- [ ] Full OSS release package (SBOM, signed artifacts, SDK docs)
- [ ] Partner integrations (Grabbey, Torqon, AIVAS) **outside** core
